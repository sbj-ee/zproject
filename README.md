# zproject

Project management for the z-suite: projects with a WBS, milestones,
dependencies, a critical-path schedule, baselines, resources and cost, a RAID
log, reports and alerts, with a Gantt chart at its centre. A small server,
`zprojectd` (C++20, Qt 6, SQLite), reachable only over Tailscale; a Qt
desktop client for Linux and macOS; and `zproject-cli`.

Status: the repository has just been created. The specification and the
build skeleton arrive in the first pull requests. Nothing is released yet.
